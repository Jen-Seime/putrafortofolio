Tentang Saya

Kombinasi antara logika sistem server yang tangguh dan estetika antarmuka web modern.

"Sebuah website bukan hanya tentang tampilan yang indah, tetapi juga tentang kecepatan muat, kestabilan server, dan keamanan data pengguna."

Saya adalah mahasiswa Semester 5 program studi Teknik Informatika / Sistem Informasi yang mendalami mata kuliah Administrasi Web. Saya terbiasa mengelola web server, konfigurasi domain & DNS, instalasi CMS, hingga deployment website ke hosting live seperti InfinityFree, cPanel, maupun VPS Linux.

Dengan pemahaman yang kuat pada HTML5, CSS3 murni, dan JavaScript modern, saya mampu membuat aplikasi web yang ringan, cepat dimuat, responsif di seluruh perangkat, dan mudah dirawat.
